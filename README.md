# 日本語 Pocket

個人利用向けの日本語学習サイト。語彙・例文は、手元の imiwa? 4.2.1 から抽出した JMdict／Tatoeba データを使用しています。

## 起動

macOS では `start.command` をダブルクリックします。ターミナルを閉じるとサーバーは停止します。Node.js がある環境では `npm install`、`npm run build`、`npm run dev` の順に実行し、表示された URL を開きます。Node 22 以降を推奨します。

学習記録、復習予定、お気に入り、追加した内容、設定はブラウザの IndexedDB に保存されます。端末やブラウザ間で自動同期されません。「設定」から JSON バックアップを書き出せます。バックアップの復元は現在の記録を上書きします。

## 現在の内容

語彙 12,000 件、例文 17,711 件、文法表現 17 件。語彙にはすべて imiwa? 内の例文が紐付いています。元データに信頼できる JLPT 語彙レベルが含まれていないため、N1／N2 の件数は未分類です。日本語と英語のデータを使用します。過去に追加した他言語のデータは削除せず、画面には表示しません。

毎日の練習と復習は、開始前に選んだ出題形式だけを繰り返します。到期した復習を優先します。空欄のまま「答えを見る」を押すと参考答えを表示し、翌日の復習に登録します。作文と翻訳は参考例と比較して自己評価します。意味の近い別表現を自動判定する機能はありません。

復習は暫定的な独自の間隔方式で、FSRS ではありません。「もう一度」は翌日、「正解」は初回 2 日後、その後は間隔を延ばします。復習の形式は自分で選べます。判定の厳密な等価性を必要とするのは語彙と書き取りのみです。

## 音声

既定では Google 翻訳のオンライン音声を使用します。語彙は可能な限り読み仮名を送ることで、漢字の読み間違いを減らしています。再生時、表示中のテキストが Google に送信されます。語彙・例文ともに再生できますが、発音の正確さは保証されません。1.5 秒の間隔を置いた 3 回再生と 0.7〜1.2 倍速に対応します。

Google 音声はローカルサーバーの `/api/tts` が必要で、インターネット接続に依存する非公式エンドポイントです。仕様変更や制限により使えなくなる可能性があります。静的な GitHub Pages 単体ではこの音声は動作しません。端末の日本語音声へ切り替えれば、端末とブラウザが対応する場合はオフライン再生できます。日本語音声が見つからない場合は通知し、他言語の音声は使用しません。

## 自分の資料を追加

設定から CSV、JSON、TXT、Markdown をインポートできます。CSV は UTF-8 で、例：

```csv
word,kana,meaning,level,example_ja,example_en
見落とす,みおとす,to overlook,N2,重要な点を見落としてはいけない。,You must not overlook important points.
```

`meaning_en`、`example_en` も利用できます。JSON は同じフィールドを持つ配列、または `items` 配列を持つオブジェクトです。TXT／Markdown は 1 行 1 例文、訳を付ける場合はタブまたは ` | ` で区切ります。語彙には意味と日語例文が必要です。例文のみでも登録できます。XLSX は未対応です。

## データの更新

`python3 scripts/build-data.py /path/to/imiwa-decoded` で `public/data/` に学習用データを再生成し、`npm run build` を実行します。学習用データはアプリ本体と分離されています。選定は形式・長さなどの機械的な条件に基づき、すべての例文の自然さや難易度を人手で検証したものではありません。JLPT 分類には、今後、出典とライセンスを確認できる対応表が必要です。

## 公開版と出典

公開版は、imiwa? 由来の例文のうち、日本語と英語訳を Tatoeba の公式データに照合できたものだけを収録しています。語彙 11,126 件、例文 16,156 件、文法表現 17 件です。日英それぞれの投稿者と原文ページへのリンクを保持しています。

語彙は [JMdict / EDRDG](https://www.edrdg.org/wiki/index.php/JMdict-EDICT_Dictionary_Project) の [CC BY-SA 4.0](https://www.edrdg.org/edrdg/newlic.html)、例文は [Tatoeba](https://tatoeba.org/) の [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/) に基づき、選択・構造を変更しています。照合に使用した公開データと再生成方法は `datasets/published/README.md` を参照してください。公開版のデータセットは `npm run build -- --published` でビルドされ、ローカル専用の元データを公開リポジトリに含めません。

公開版の語彙は、imiwa? で選んだ項目を 2026-10-26 の JMdict に照合・更新しています。定期的に [jmdict-simplified の最新リリース](https://github.com/scriptin/jmdict-simplified/releases/latest) の `jmdict-eng-*.json.tgz` を取得し、`python3 scripts/update-public-jmdict.py /path/to/jmdict-eng-VERSION.json.tgz` を実行して更新できます。公開後は少なくとも毎月データを更新してください。

GitHub Pages 版は静的サイトのため、ブラウザの日本語音声を使用します。利用できる場合は Google 日本語音声を優先し、それ以外は端末の日本語音声を使用します。音声の種類と品質はブラウザと端末によって異なります。
